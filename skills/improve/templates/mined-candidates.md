## 1. 分页参数要有上限

- **候选**:1(2 个 MR;评审人 2 位)
- **去向**:.agents/rules/api.md
- **动作**:待定
- **复核**:
- **规则**:在 src/api/** 的接口里,必须校验分页参数 limit 的上限
- **原因**:不校验时传入很大的 limit 会一次查出全表
- **严重级别**:重要
- **情形**:订单列表接口把请求里的 limit 直接传给查询,传很大的值会读出整表;正例给 limit 加了默认值和上限
- **范围**:src/api/**
- **反例**:
  ```ts
  router.get('/orders', async (req, res) => {
    res.json(await repo.list({ limit: req.query.limit }))
  })
  ```
- **正例**:
  ```ts
  router.get('/orders', async (req, res) => {
    res.json(await repo.list({ limit: Math.min(Number(req.query.limit) || 20, 100) }))
  })
  ```
- **不要报**:离线导出接口不限

> 语义复核(模型判断):两个独立 MR 都要求接口分页参数遵守项目上限;离线导出不使用同一协议。
